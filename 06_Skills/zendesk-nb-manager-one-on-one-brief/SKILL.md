# Zendesk New Business manager one-on-one brief

Read [the manager contract](../../references/shared/zendesk-manager-inspection-contract.md), [the evidence/process contract](../../references/shared/zendesk-evidence-and-process.md), and [the tool-access contract](../../references/shared/seller-tool-access-contract.md).

Resolve exact rep, period, prior commitments, current pipeline/forecast, selected deals, territory creation, calendar/weekly rhythm, and known blockers. Separate business decisions, execution quality, skill development, system/data friction, and manager support.

Prepare an agenda beginning with the rep's perspective, then inspect one pipeline/deal decision and one development priority using direct evidence. Use Gong only when call-specific coaching is in scope. End with no more than three dated, observable rep and manager commitments. Avoid surprise performance conclusions and generic activity coaching.

Return context, wins, business inspection, coaching questions, blocker decisions, development focus, commitments, and next-review evidence. State that no forecast, CRM, message, calendar, or performance record was changed.

For behavioral validation, use [evaluation cases](references/evaluation-cases.md).
