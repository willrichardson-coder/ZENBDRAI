# Zendesk New Business manager territory and pipeline

Read [the manager contract](../../references/shared/zendesk-manager-inspection-contract.md), [the evidence/process contract](../../references/shared/zendesk-evidence-and-process.md), and [the tool-access contract](../../references/shared/seller-tool-access-contract.md).

Core evidence is exact hierarchy/rep/account/opportunity IDs, territory ownership, period, source and stage definitions, current pipeline, prior snapshots, capacity, and exclusions. Current Salesforce/Snowflake or Clari/Sales Pulse evidence is required for live judgments.

Inspect coverage, creation by source, stage movement, aging, concentration, account penetration, fast-start versus strategic mix, active-deal conflicts, and rep capacity. Keep activity, created pipeline, qualified pipeline, forecast, and bookings distinct. Use Common Room or scores only as prioritization evidence. Identify the smallest manager intervention for each material pattern.

Return team snapshot, source/stage movement, coverage and concentration, rep-level questions, focus decisions, manager interventions, data defects, and next review. State that no territory, report, opportunity, or forecast was changed.

For behavioral validation, use [evaluation cases](references/evaluation-cases.md).
