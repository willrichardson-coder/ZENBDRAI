# Zendesk BDR manager territory planning

Read [the manager contract](../../references/shared/zendesk-manager-inspection-contract.md), [the evidence/process contract](../../references/shared/zendesk-evidence-and-process.md), and [the tool-access contract](../../references/shared/seller-tool-access-contract.md).

Core evidence is exact rep/AE/account ownership, territory scope, period, capacity, active opportunities, exclusions, approved plays, and current fit/signal definitions. Reconcile Salesforce/Snowflake identity before adding Common Room or contact-data signals.

Assess coverage, concentration, account aging, motion/source mix, play fit, contactability, AE alignment, and capacity. Use scores to prioritize human review, preserve source-specific definitions, and show which accounts cannot yet be actioned. Recommend focus bands, named tradeoffs, and a review cadence based on current team practice.

Return a territory plan with source definitions, capacity, coverage gaps, focus bands, AE/BDR coordination, exclusions, data defects, and manager actions. State that no assignment, list, report, or account was changed.

For behavioral validation, use [evaluation cases](references/evaluation-cases.md).
