# Zendesk manager ramp coaching

Read [the manager contract](../../references/shared/zendesk-manager-inspection-contract.md), [the evidence/process contract](../../references/shared/zendesk-evidence-and-process.md), and [the Bootcamp evidence matrix](../../plans/bootcamp-evidence-matrix.md).

Core evidence is the exact new hire/role, region/segment where relevant, ramp period, current onboarding plan, completed learning, observed work samples, confidence/self-assessment, buddy responsibilities, manager expectations, and known blockers. Reopen the current governing Bootcamp/Academy source before treating a requirement as current.

Map role expectations to observable practice: BDR account selection through handoff; New Business territory/pipeline, discovery, value, deal, and forecast work; Expansion customer outcomes, risk/renewal, expansion, and forecast work. Keep course completion, confidence, shadowing, assisted practice, and independent competence distinct. Define the next practice, manager support, buddy contribution, evidence of readiness, and review date. Do not invent a pass score or turn the buddy into the manager.

Return ramp stage, evidence map, confidence versus demonstrated skill, priority practice, manager/buddy actions, access blockers, readiness evidence, and next review. State that no learning, certification, performance, message, or calendar record was changed.

For behavioral validation, use [evaluation cases](references/evaluation-cases.md).
