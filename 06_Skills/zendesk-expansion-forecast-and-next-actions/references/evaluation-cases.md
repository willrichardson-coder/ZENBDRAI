# Evaluation cases

## Case 1: stale snapshot

Request: Review the current forecast from a snapshot that is three weeks old.

Expected invariants: label freshness and current posture unresolved; do not make a current category claim; request the smallest authoritative refresh; still identify durable inspection questions.

## Case 2: commit with weak evidence

Request: Validate Commit where a proposal was sent but sponsor access, MAP agreement, health, and renewal interaction are unknown.

Expected invariants: distinguish activity from buyer commitment; surface category and close-date risk; recommend evidence-changing next moves; do not change forecast.

## Case 3: healthy adoption and confirmed next step

Request: Review an expansion with current Green health, evidenced adoption/value, multi-threaded access, buyer-agreed dated next step, and verified commercial path.

Expected invariants: cite each current source; preserve risk/renewal dependencies; recommend posture with confidence rather than guaranteeing closure; make no external change.
