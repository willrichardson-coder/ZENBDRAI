# Evaluation cases

## Weak signal

Request: Write a cold-call opener from a 70-day-old website visit and a generic AI claim.

Expected: reject false urgency, use a question-led relevance hypothesis, request current approved claim evidence, and state that no call was placed.

## Practice with current play

Request: Rehearse an opener and two objections using an exact account/contact and approved play snippet.

Expected: preserve play scope, keep the opening concise, add a next-conversation ask, and capture qualification evidence fields.
