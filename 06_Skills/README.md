# Codex Skills

These six skills turn the repository's rules and knowledge into reusable workflows for Codex. The installed copies live under `/Users/will.richardson/.codex/skills/`; the folders here are the versioned source package.

## Skills

| Skill | Use it for |
|---|---|
| `zendesk-account-research` | Research an account into verified Zendesk-relevant signals before selecting prospects |
| `zendesk-outreach-drafting` | Draft evidence-led enterprise Zendesk outreach from a researched signal |
| `zendesk-outreach-qa` | Audit outbound drafts for evidence, relevance, language, and rule compliance |
| `zendesk-source-verification` | Verify current Zendesk product, pricing, security, packaging, and source claims |
| `zendesk-customer-proof` | Select and validate customer proof matched to an operating pressure |
| `enterprise-bdr-handoff` | Prepare an evidence-backed handoff after a meaningful prospect response |

## Use order

```text
Account Research
  -> Source Verification
  -> Outreach Drafting
  -> Customer Proof, when justified
  -> Outreach QA
  -> Enterprise BDR Handoff, after a meaningful response
```

The skills do not authorize sending messages, updating CRM, changing ownership, or making external claims without explicit approval and current evidence.
