# Zendesk New Business manager forecast review

Read [the manager contract](../../references/shared/zendesk-manager-inspection-contract.md), [the evidence/process contract](../../references/shared/zendesk-evidence-and-process.md), and [the tool-access contract](../../references/shared/seller-tool-access-contract.md).

Require exact team/rep/opportunity IDs, review period, as-of date, current forecast categories and definitions, stage, amount, close date, prior snapshot, and recent buyer evidence. Reconcile Clari/Sales Pulse with verified Salesforce/Snowflake fields; preserve disagreements.

Prioritize Commit, then Most Likely, while inspecting real movement, signing authority/Economic Buyer access, value narrative, stakeholder coverage, mutual actions, confirmed dated next step, procurement/security/legal path, and close-date feasibility. Separate rollup arithmetic, deal judgment, data hygiene, and coaching. Do not invent category thresholds or manipulate dates.

Return rollup and movement, deal-level posture, contradictions, forecast recommendation, confidence, rep follow-ups, manager actions, and access gaps. State that no forecast or CRM field was changed.

For behavioral validation, use [evaluation cases](references/evaluation-cases.md).
