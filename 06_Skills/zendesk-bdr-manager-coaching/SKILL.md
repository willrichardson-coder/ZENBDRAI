# Zendesk BDR manager coaching

Read [the manager contract](../../references/shared/zendesk-manager-inspection-contract.md), [the evidence/process contract](../../references/shared/zendesk-evidence-and-process.md), and [the tool-access contract](../../references/shared/seller-tool-access-contract.md).

Core evidence is the exact rep, review period, selected competency, expected Zendesk workflow, and one or more observed artifacts. Use Salesforce/Snowflake, Seismic, Common Room, Groove read evidence, and Gong MCP as relevant. Without direct work evidence, prepare a coaching plan but do not grade execution.

Compare the work with the role-specific standard; name one repeatable strength, one highest-leverage upgrade, the exact moment or artifact that supports it, and practice language or a practice task. Keep data quality, workflow friction, manager enablement, and rep behavior separate. For calls, use transcript moments and require Gong or an authoritative recording/transcript.

Return a coaching brief with evidence, competency diagnosis, feedback, practice, success evidence, rep commitment, manager support, and next review. State that no message, activity, or performance record was changed.

For behavioral validation, use [evaluation cases](references/evaluation-cases.md).
