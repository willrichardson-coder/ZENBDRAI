# Zendesk BDR Shared Framework

One shared operating system. Each teammate changes only their assigned accounts and aligned AEs.

## Three-step setup

1. Fork or clone this repository and open the folder as a local Codex project.
2. Copy `00_My_Workspace/MY_ASSIGNMENTS.template.md` to `00_My_Workspace/MY_ASSIGNMENTS.md`.
3. Run `python3 scripts/install_team_skills.py`, then replace the sample assignment row with your accounts and aligned AEs.

Your assignment file and account work are excluded from Git. Rules, knowledge, templates, examples, and all 48 custom skills remain shared.

Read `START_HERE.md` for the operating model and `SETUP_INSTRUCTIONS.md` for the first test.

## Start working

Ask:

> Research [Account] from my assignments, build the signal map, recommend the right prospects, and draft outreach only after the account case is clear.

The framework will confirm the account and AE, research the account before people, separate facts from assumptions, and audit drafts before delivery.

It will not send outreach, update CRM, or change ownership without explicit approval.

## Shared changes

Account and AE changes stay local. Changes that should apply to everyone use a branch and pull request under `CONTRIBUTING.md`.
